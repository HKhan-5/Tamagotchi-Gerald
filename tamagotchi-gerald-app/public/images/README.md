# Images Directory

Place your images here with the following naming:

## Gerald Image:
- `gerald.png` (or .jpg, .gif) - The main character image

## Decoration Images:
- `flower-pink.png` - Pink Flower decoration
- `flower-sun.png` - Sunflower decoration
- `mushroom.png` - Mushroom decoration
- `butterfly.png` - Butterfly decoration
- `rainbow.png` - Rainbow decoration
- `star.png` - Star decoration
- `moon.png` - Moon decoration
- `bee.png` - Bee decoration

## Gacha Button Image:
- `gacha-button.png` - The gacha machine button image

You can use any image format (.png, .jpg, .jpeg, .gif, .webp)
Recommended size: 100x100 to 500x500 pixels for best quality
